## 🌟 Project Overview

This is a clean and responsive personal portfolio website built with **HTML5**, **CSS3**,  It is designed to present my skills, projects, and contact information in a professional and organized manner.

The portfolio includes:

- **Hero Section:** Introduction and call-to-action button.
- **About Section:** Brief introduction about myself and my journey.
- **Skills Section:** Showcase of my technical skills.
- **Projects Section:** Highlights of completed and in-progress projects.
- **Contact Section:** Contact form for visitors to reach out.
- **Footer:** Project information and credits.

---

## 🛠️ Features

- Responsive design for desktop, tablet, and mobile screens
- Semantic HTML5 structure
- Custom CSS styling
- Project status indicators (`Done` / `In Progress`)
- Simple contact form layout
